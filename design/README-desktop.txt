RailPilot {version} · Windows 桌面版

完整解压后打开 RailPilotGUI.exe。查票及扫码使用 Microsoft Edge。

在「查票」填日期、出发站和到达站。选中车次，点击「加入行程」，勾选接受的席别。
可继续查其他日期和车次，再到「我的行程」调整顺序、填写乘车人和最晚到达时间。
同一行程的备选覆盖同一乘车区间。行程草稿和待核实记录使用当前 Windows 用户的 DPAPI 加密。

扫码后，「跟踪手动预订」会先读取原有订单，再打开官方页面。由你在官方页面提交订单。
「有票时提交一次」按确认的成人票行程低频查询，表单完全匹配才尝试提交。付款由你完成。
「核对订单」会核验新订单的车次、日期、区间、席别、乘车人和时间。重启后重新扫码可继续核实。
页面或网络状态不明确时，在「打开官方订单」核对。支付期限以 12306 显示为准。

本版本已使用模拟订单验证提交与恢复流程。真实账号的下单与支付留给你在实际购票时确认。
